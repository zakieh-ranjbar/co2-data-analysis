# CO2 Data Analysis

برای تمرین تحلیل داده، این مجموعه‌دادهٔ مربوط به خودروها را انتخاب کردم و بررسی کردم که حجم موتور، تعداد سیلندر و مصرف سوخت چه ارتباطی با مقدار CO2 دارند. داده‌ها ۵۰۰ رکورد دارند. اول یک نگاه کلی به اعداد انداختم و بعد با چند نمودار سعی کردم رابطهٔ بین ویژگی‌های خودرو و خروجی CO2 را بهتر ببینم. فایل‌های پروژه هم طوری مرتب شده‌اند که اگر داده تغییر کند، بتوانم تحلیل و نمودارها را دوباره اجرا کنم.

## داده‌ها

فایل خام در `data/co2.csv` قرار دارد و ستون‌های اصلی آن بدون تغییر حفظ شده‌اند:

| ستون خام | تفسیر استفاده‌شده در پروژه |
|---|---|
| `engine` | حجم موتور |
| `cylandr` | تعداد سیلندر؛ نام خام برای سازگاری حفظ شده است |
| `fuelcomb` | مصرف ترکیبی سوخت |
| `out1` | خروجی CO2 در دیتاست |

دیتاست ۵۰۰ رکورد دارد و هیچ مقدار گمشده‌ای ندارد. چون واحد ستون‌ها در فایل مشخص نشده است، گزارش از تعیین واحد قطعی خودداری می‌کند.

## یافته‌های پایه

- مجموع ۵۰۰ مقدار اول `out1`: **۱۳۴٬۰۱۳**
- میانگین `out1`: **۲۶۸٫۰۲۶**
- کمینه: **۱۱۰**
- بیشینه: **۴۸۸**
- انحراف معیار: **۶۷٫۱۰۰**

همبستگی پیرسون برای پیدا کردن رابطهٔ خطی بین ویژگی‌ها و `out1` در فایل `outputs/summary.json` ذخیره می‌شود. همبستگی به معنی رابطهٔ علّی نیست.

## نصب و اجرا

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\\Scripts\\activate
pip install -r requirements-dev.txt
```

ساخت گزارش عددی و نمودارها:

```bash
python -m src.analysis
python -m src.visualize
```

اجرای تست‌ها:

```bash
pytest
```

## نوت‌بوک

نسخهٔ اصلی ارسالی در `notebooks/co2_original.ipynb` نگهداری شده است. کد قابل تکرار و قابل استفاده در پروژه در پوشهٔ `src/` قرار دارد.

- `outputs/summary.json`: آمار، مقادیر گمشده و همبستگی‌ها
